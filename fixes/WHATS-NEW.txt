# What the fixes' catalog brings since the one before it: a line for each thing, in
# words for whoever plays, the game first. The build puts these lines into
# catalog.json as "notes"; the app shows them with the update and the agent in its
# notification. Rewrite them with every change to the fixes: what stays here is said
# again with the next catalog. Lines that start with # are not carried.
Forza Horizon 5: on NotProton (CrossOver Preview 41303, Rosetta) the game no longer closes while you sign in to Xbox. The fix gives the game a NotProton row, Xbox sign-in window, and switches it on, so quit Steam before installing.
F1 25, being tested: Steam's Play starts it through Swofty Launcher on NotProton (CrossOver Preview 41303, Rosetta), offline and without EA AntiCheat. You download Swofty Launcher yourself; the install asks where the download is and copies it, and MacGameFix does not include it. The crash half a minute in is now fixed for F1 25 alone, by MacGameFix's Engine fixes row, so the fix no longer needs the Rosetta improvement's memory patch. It has no NotProton row of its own any more: it uses MacGameFix's shared rows, Engine fixes, Start through the mod tool, Play opens and Mod profile, which offers your Swofty profiles by name. Turn Testing on in Settings to see it; it needs an up-to-date NotProton, and Steam closed while it installs. At your own risk: MacGameFix does not answer for failures in the game.
EA SPORTS FC 27, being tested: Steam's Play starts it with FC 27 Live Editor on NotProton (CrossOver Preview 41303, Rosetta), offline and without EA AntiCheat. The Windows function its activation asks for is now added for FC 27 alone, by MacGameFix's Engine fixes row, so the fix no longer needs the Rosetta improvement's kernel32. It has no NotProton row of its own any more: it uses MacGameFix's shared rows, Engine fixes, Start through the mod tool and Play opens. You download Live Editor yourself; the install asks for its folder and copies it, and MacGameFix does not include it. Turn Testing on in Settings to see it; it needs an up-to-date NotProton, and Steam closed while it installs. At your own risk: MacGameFix does not answer for failures in the game.
Forza Horizon 6: on NotProton (CrossOver Preview 41303, Rosetta) its Wine fixes for the timer thread, the online sessions' sockets and the protection's system calls during a suspend now come from MacGameFix's Engine fixes row, which the improvement switches on for FH6, on NotProton's own ntdll. Played that way, online included. Quit Steam before installing, so the row can be switched on.
Phantom Blade Zero: on NotProton (CrossOver Preview 41303, Rosetta) the fix no longer needs the Rosetta improvement: MacGameFix's Engine fixes row, which the fix switches on, shows its copy protection the CPU it checks for, on NotProton's own ntdll. Played that way. A CrossOver bottle still needs the improvement. Quit Steam before installing, so the row can be switched on.
Red Dead Redemption 2: Red Dead Online's connection fix no longer needs the Rosetta improvement's ntdll, which NotProton's 41303 runner no longer has. It switches on NotProton's Red Dead Online fix row for the game, which MacGameFix puts in place, so quit Steam before installing. It also gives the Rockstar Games Launcher the window fix it needs on that runner, which otherwise times out before its window shows. Install it again if you had it. Red Dead Online was played that way.
Forza Horizon 6: the exception handling that makes the game playable under Rosetta (58 frames a second against 48, and a frame over 100 ms in 2% of seconds against 69%, same route) now comes from the game's own D3D12 proxy, hooked into the ntdll.dll NotProton ships. On NotProton's 41303 runner the improvement and the Wine modules no longer replace ntdll.dll: FH6 runs on NotProton's own, with its Steam bridge, and played as before. Installing again puts NotProton's back where an earlier version had put ours.
