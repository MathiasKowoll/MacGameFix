CrossOver Preview 41303: Forza Horizon 5 no longer closes while you sign in to Xbox. The sign-in page's browser stopped on a Wine check, and the game went with it.
CrossOver Preview 41303: F1 25 no longer closes half a minute after it starts. Wine gave the game memory at addresses it cannot use; it gets low ones again.
CrossOver Preview 41303: Swofty Launcher's window opens, and so can other programs built the same way: Wine can now look their fonts up and lets them set up touchpad gestures, which still do nothing.
CrossOver Preview 41303: EA SPORTS FC 27 starts instead of stopping at "There is a problem with your game's setup. Please reinstall your game." Wine lacked a Windows function the game asks for; it has it now, and it answers that no Windows package is installed.
