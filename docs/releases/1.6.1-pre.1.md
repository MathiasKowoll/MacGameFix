# MacGameFix 1.6.1-pre.1 — Forza compatibility preview

## Status

- **Forza Horizon 5: complete, gameplay validated on this Mac.** Includes the source-built D3D12 and Xbox sign-in/network compatibility fixes. This is not a claim of universal hardware, multiplayer or every game-mode coverage.
- **Forza Horizon 6: WIP with advances.** Xbox sign-in, menu, loading and actual driving have passed with the retained Rosetta baseline. The user reports smooth driving at approximately 60 FPS with few drops. Other routes, hardware and long sessions remain open. FEX/Mullion is not the supported route for this preview.

## Existing Rosetta improvement

No new Improvements section. Preview 27.0.0.41073 receives the matching x86_64 Unix/PE ntdll pair in **Copy protection under Rosetta**. It includes the earlier CPU fixes, patch 0021 for relative-timer overflow and the guarded FH6 exception dispatcher. Older CrossOver builds retain their current modules; this Wine 11.17 pair must not be copied into Wine 10 or ARM64.

The FH6 installer coordinates the prefix and NotProton launch clone, applies the required game-specific launch options, and installs the Rosetta exception-priority plugin when absent. Steam must be closed if its launch options need changing. It preserves unrelated options and an already configured diagnostic HUD. New installations default to aggregate counters off, without forcing the HUD or an FPS limit. The Games table's **Diagnostics** menu enables/disables the HUD, HUD log and aggregate counters for the next launch. Detailed probes remain off.

The game executable is hash-gated. Handler ordering, original faults, register/SIMD results and flags remain required. The fast path falls back on unsupported or ambiguous operations. No game executable or license logic is altered.

## Retained baseline and measurements

`fh6-baseline.json` records the exact installed binaries and launch options validated on 2026-11-11. Distribution signing may change the Mach-O signature but must leave its executable code identical. The existing installed experiment is not replaced during packaging.

The first 40-second driving capture changed from 46.14 FPS with 37 frames above 50 ms on the prior version to 57.02 FPS with 21 such frames on the retained version. A second driving capture averaged 27.10 FPS with 57 frames above 50 ms. The user nevertheless reported no perceptible recurring hitch and subsequently approximately 60 FPS outside measurement. Routes and conditions were not controlled; measurement-induced slowdown is a hypothesis, not a demonstrated cause. These are not a universal benchmark or a promise of fixed 60 FPS.

Semantic validation before integration: 1,090 authored instruction cases, 132,160 full-state comparisons per mode, five modes plus additional disabled/diagnostic variants; 28 destination/path fixtures over 64 flag seeds; 1,490 PE exports preserved. Package/installer validation is recorded separately. Counters-off gameplay still requires a separate driving check.

## Downloads and updates

This preview app uses the GitHub tag `v1.6.1-pre.1` for its signed fix/module catalogs. Stable MacGameFix continues using the stable `latest` release. Both catalogs require app 1.6.1, so an older installer cannot misclassify the new PE ntdll as a controller module. A GitHub draft is not downloadable by the app until the prerelease is published.
